# Site Watch RSS

Небольшой мониторинг изменений сайтов на GitHub Actions с выдачей результатов через RSS.

## Что отслеживается

Сейчас в `sites.json` добавлены:

- https://ac-u.ru/
- https://ac-u.ru/seo/
- https://ac-u.ru/sozdanie-saitov/
- https://nan.ru/
- https://www.web-canape.ru/
- https://artena.ru/

Скрипт отслеживает:

- TITLE
- META DESCRIPTION
- H1
- H2
- H3
- заметные текстовые блоки
- внутренние ссылки

Первый запуск только сохраняет исходное состояние. RSS-записи появятся после обнаружения последующих изменений.

## Как запустить

1. Создайте новый GitHub-репозиторий.
2. Загрузите в него все файлы из этого архива, сохранив структуру папок.
3. Откройте:
   `Settings → Actions → General`
4. В разделе **Workflow permissions** включите:
   `Read and write permissions`
5. Сохраните.
6. Откройте:
   `Settings → Pages`
7. В качестве Source выберите:
   `GitHub Actions`
8. Перейдите во вкладку:
   `Actions`
9. Откройте workflow:
   `Site Watch RSS`
10. Нажмите:
    `Run workflow`

После первого запуска будут заполнены `state.json` и создан `docs/feed.xml`.

## Расписание

Workflow настроен на:

`17 * * * *`

Это означает проверку примерно каждый час на 17-й минуте.

GitHub Actions не гарантирует запуск секунда в секунду, поэтому возможна небольшая задержка.

## RSS-адрес

После включения GitHub Pages адрес обычно имеет вид:

`https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/feed.xml`

Именно его можно добавить в RSS-reader.

## Как добавить сайт

Откройте `sites.json` и добавьте объект:

```json
{
  "name": "Название",
  "url": "https://example.com/"
}
```

## Важно

Этот вариант мониторит только URL, перечисленные в `sites.json`.

Он пока не обходит автоматически весь сайт и `sitemap.xml`.
